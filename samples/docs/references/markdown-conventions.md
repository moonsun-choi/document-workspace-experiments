# 문서 작성 규칙

## 머리말(frontmatter)

모든 문서는 맨 위에 다음 정보를 둔다.

```yaml
---
title: 문서 제목
tags: [태그1, 태그2]
date: 2026-10-01
---
```

## 문서 간 링크

`[[파일이름]]` 형식으로 다른 문서를 연결한다. 폴더가 달라도 파일 이름이 겹치지 않으면 이름만 쓰면 된다. 표시 이름을 바꾸려면 `[[파일이름|보여 줄 글자]]`라고 쓴다.

예: [[glossary|용어집]]

## 폴더

- `research/`: 조사 노트
- `planning/`: 계획
- `meetings/`: 회의록
- `references/`: 규칙과 참고 자료
- `inbox/`: 아직 정리하지 않은 메모
