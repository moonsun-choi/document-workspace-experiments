# 화면 구성 스케치

## 공통

상단 내비게이션: 문서 · 그래프 · 비교 · 질문 · 실험 기록. 오른쪽에 "선택한 문서 n개" 표시.

## 문서 화면

- 왼쪽: 폴더 트리
- 가운데: 검색창, 태그 칩, 결과 목록
- 문서를 열면 본문과 함께 "이 문서를 참조하는 문서(백링크)"를 보여 준다.

## 선택 바구니

문서마다 "선택" 버튼이 있고, 선택한 문서는 비교 화면과 질문 화면에서 같이 쓴다.
