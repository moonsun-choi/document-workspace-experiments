# 로드맵

## 1단계: 샘플 문서 + UI + 검색

- 폴더별 Markdown 문서 탐색
- 키워드 검색과 태그 필터
- 문서 간 링크 그래프
- 여러 문서 비교와 추출 요약 (AI 없이)
- 선택한 문서에서 근거 문단 찾기 (AI 없이)
- 실험 기록 보기

상세 범위는 [[mvp-scope]] 참고.

## 2단계: 임베딩과 하이브리드 검색

- 문서 조각 임베딩 생성 ([[embeddings]], [[chunking]])
- 키워드 점수와 벡터 점수를 합친 하이브리드 검색

## 3단계: RAG 질의응답

- 선택한 문서 기반으로 답변 생성 ([[rag-basics]])
- 답변마다 근거 문단 표시
- 프롬프트와 결과를 실험 기록으로 자동 저장
